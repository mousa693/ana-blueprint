# The Agency AI Client-Onboarding Checklist

**Who this is for:** agencies and freelancers who use AI to produce social content for clients.
**What you'll get:** a repeatable process to capture a client's brand voice, visuals, audience and constraints in a form your AI tools can use, plus templates to copy.
**How to use it:** duplicate this checklist for each new client. Tick each box. Don't skip Phase 4.

---

## Phase 0: Before the contract is signed

- [ ] Confirm which **platforms** you'll manage (e.g. Instagram, Facebook, Threads, LinkedIn).
- [ ] Confirm **who approves** content on the client side, and the turnaround time.
- [ ] Agree whether AI-assisted content needs to be **disclosed** under the client's policies or industry rules.
- [ ] Confirm **image and likeness rights**: can you use photos of staff, customers or premises?
- [ ] Note any **regulated categories** (finance, health, alcohol, gambling, legal) that limit claims.

## Phase 1: Collect source material (send with the contract)

Copy this request into your welcome email:

> To get your brand set up quickly, please send:
> 1. Your website URL and any official social profiles
> 2. 3–5 posts or ads (yours or anyone's) you love, and one sentence on why
> 3. 3 posts you'd never publish, and why
> 4. Words, phrases or claims we must never use
> 5. Your main audience in one sentence
> 6. Your #1 goal for the next 90 days
> 7. Brand guidelines, logo files and fonts (if you have them)
> 8. Approved proof points: stats, testimonials, awards, press

- [ ] Website URL received
- [ ] Social profile links received
- [ ] "Love" examples (3–5) with reasons
- [ ] "Never" examples (3) with reasons
- [ ] Banned words and claims list
- [ ] Audience sentence
- [ ] 90-day goal
- [ ] Brand guidelines / logo / fonts
- [ ] Approved proof points

## Phase 2: Build the brand profile

- [ ] Create a **separate brand** (or brand workspace) for this client. Never reuse another client's.
- [ ] Name it clearly: `ClientName` or `ClientName – SubBrand`.
- [ ] Run an **AI brand import** from the official website (or main social profile if the site is thin).
  - *In Fuzzbucket: choose "Import my existing brand", share the link, answer clarification questions, and accept only accurate items.*
- [ ] Confirm the **identity** summary (what they do, positioning).
- [ ] Confirm the **audience** is specific enough to change word choice.
- [ ] Confirm the **visual guidance**: current logo, exact palette, photo or illustration style.
- [ ] Confirm **products/services** are current and correctly named.
- [ ] Remove any **claims the AI inferred** that the client hasn't stated or approved.
- [ ] Save approved **brand media** (product shots, team photos, location images) with their source.

## Phase 3: Write the voice & rules document (one page max)

Copy this template into the brand's knowledge base (in Fuzzbucket: a Knowledge document shared with agents).

```markdown
# [ClientName] – Voice & Rules

## Voice (3–5 pairs)
- [Adjective], not [opposite]   e.g. Confident, not arrogant
- [Adjective], not [opposite]
- [Adjective], not [opposite]

## We sound like…
- Example line: "…"
- Example line: "…"

## We never sound like…
- Example line: "…"

## Language rules
- Spelling: [UK / US / AU / CA]
- Emojis: [none / max 1 / platform-specific]
- Hashtags: [none / max N / branded tags only]
- Say "[preferred term]", never "[avoided term]"

## Banned words & claims
- …

## Approved proof points (only use these)
- Stat: "…" (source: …)
- Testimonial: "…" (approved by client on [date])

## Platform dials
- Instagram: …
- Facebook: …
- Threads: …

## Legal / compliance notes
- …

## Competitors (do not mention / how to reference)
- …
```

- [ ] Voice pairs completed
- [ ] "Sound like" and "never sound like" examples added
- [ ] Language rules set
- [ ] Banned words and claims added
- [ ] Approved proof points added (with source)
- [ ] Platform dials set for every managed platform
- [ ] Compliance notes added
- [ ] Document saved where the AI reads it automatically, not in a separate drive folder

## Phase 4: Calibration batch (before any live content)

Generate a small test set inside the client's brand workspace:

- [ ] 3 Instagram captions (short, medium, long)
- [ ] 2 Facebook posts
- [ ] 2 Threads posts
- [ ] 2–3 visuals in the proposed style
- [ ] Run internal QA (Phase 5 checks) before sending

Send to the client with this scoring request:

> For each item, mark **Sounds like us / Close / Not us** and give one reason.

- [ ] Client feedback received
- [ ] Every "Close" or "Not us" reason added to the Voice & Rules doc
- [ ] Second mini-batch generated if more than 30% were "Not us"
- [ ] Client sign-off on voice recorded (date: ______)

## Phase 5: QA gate (use for every batch, forever)

| ✔ | Check |
|---|---|
| ☐ | Generated in the **correct client's** brand workspace |
| ☐ | Matches voice pairs, including the "not" side |
| ☐ | Every fact, price, date and offer is client-approved |
| ☐ | No banned words or claims |
| ☐ | Correct logo, palette, current products/packaging |
| ☐ | No competitor names, slogans or look-alike visuals |
| ☐ | Right format, length and aspect ratio for each platform |
| ☐ | Image and likeness rights cleared |
| ☐ | Required disclosures present |
| ☐ | Read aloud: sounds like one consistent brand |

## Phase 6: First plan

- [ ] Objective for the first 30 days
- [ ] One KPI per objective (e.g. saves, clicks to booking page)
- [ ] Role of each platform defined
- [ ] Core message in one sentence
- [ ] Calendar entries created with owners and due dates
  - *In Fuzzbucket: marketing plans turn reviewed brand context into an objective, checklist, calendar entries and next actions.*
- [ ] Client approved the plan

## Phase 7: Publishing setup

- [ ] Client's social accounts connected (with the correct permissions)
- [ ] Test post scheduled to a low-risk slot and confirmed live
- [ ] Posting times agreed
- [ ] Escalation contact for urgent removals
  - *In Fuzzbucket: connect Meta, choose Facebook Page, Instagram account and Threads profile targets, then schedule or publish with visible job status.*

## Phase 8: Learning loop (monthly)

- [ ] Top 3 posts by saves, comments and clicks recorded
- [ ] One format that worked, one that didn't
- [ ] One voice or visual adjustment added to Voice & Rules
- [ ] Brand profile reviewed after any rebrand, launch or quarter end
- [ ] Next month's objective set

## Onboarding timeline at a glance

| Day | Milestone |
|---|---|
| Contract day | Phase 0 confirmed, Phase 1 request sent |
| Day 1–2 | Sources received → Phase 2 brand profile built |
| Day 2–3 | Phase 3 Voice & Rules drafted |
| Day 3–5 | Phase 4 calibration batch and client feedback |
| Day 5–7 | Phase 6 first plan approved, Phase 7 publishing set up |
